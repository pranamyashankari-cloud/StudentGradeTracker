# CodeAlpha Student Grade Tracker

A console-based Java application for recording student marks and generating grade reports.

## Features
- Add students with unique roll numbers and marks for multiple subjects.
- Calculate average, highest, and lowest marks.
- Display all student reports or search by roll number.
- Validate marks (0–100) and handle invalid input.

## Requirements
- Java 17 or newer

## Run
```bash
javac src/StudentGradeTracker.java
java -cp src StudentGradeTracker
```

## Concepts used
Classes and objects, `ArrayList`, streams, loops, methods, and input validation.
